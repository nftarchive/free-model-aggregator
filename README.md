Free-model aggregator: probes every provider's catalog, builds one catalog, and routes each request to the strongest free model that meets its requirements, with load-aware planning and failover — so no one provider's free-tier budget runs out mid-trial.

## Run it

```sh
node main.ts
```

`node main.ts --list` prints the catalog JSON and exits before any server starts.
